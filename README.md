Workout Planner

This is a small Python project I built to keep track of workout days and exercises. It is a simple personal tool for organizing training plans without needing to use a spreadsheet or a bigger app.

What it does

- Lets the user enter workout days
- Lets the user add exercises for each day
- Stores the number of sets, weight, and reps
- Prints a summary at the end so the workout plan is easy to review

How to run, follow the prompts:

1. Enter the workout day name
2. Add exercises for that day
3. Type `another` when you want to move to a new day
4. Type `done` when you are finished adding exercises or days
